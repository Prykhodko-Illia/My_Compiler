tests/err, as produced in the five steps above, one commit per step.

(MemberFn and MemberCall stay in the tree); read and print as keywords, so using either as a name

call site for a result a member function is called on.

exit (`exit a + b`); my compiler rejected them, correctly, since exit takes a factor, and the AI
rewrote them with a variable before checking the expected results.
